# MaxMix / 맥스믹스

**Mac의 소리를 메뉴바 한곳에서 조절하세요.**

MaxMix는 앱마다 다른 볼륨을 설정하고, 원하는 소리에 집중할 수 있는 macOS 오디오 앱입니다.
전체 출력과 마이크, 앱별 믹서와 마이크 EQ를 하나의 메뉴바에서 관리합니다.
아이폰 Handoff 전화기능 이용시, 자동 bypass 전환으로 메뉴바 및 사운드 드라이버 먹통현상을 방지합니다.

## 다운로드

**[다운로드 · MaxMix 0.2.1](https://github.com/Siwolmoon/MaxMix-App/releases/tag/v0.2.1)**

macOS 26 이상 / Apple Silicon
DMG를 열고 **MaxMix.app을 Applications 폴더로 드래그**한 뒤 실행하세요.
앱은 메뉴바에 나타납니다.

## 주요 기능

- **앱별 볼륨과 음소거** — 다른 앱의 소리를 각각 조절합니다.
- **Focus** — 특정앱의 소리만 켜고, 나머지 사운드소스를 0으로 만듭니다.
- **자동 앱 목록과 즐겨찾기** — 오디오 소스를 등록한 실행 앱을 표시하고 즐겨찾기를 위쪽에 유지합니다.
- **출력장치와 마이크 조절** — 장치를 선택하고, 하드웨어가 지원하는 볼륨과 입력 게인을 조절합니다.
- **마이크 EQ** — 10개 주파수 밴드와 프리셋으로 입력 소리를 조정하고 선택한 출력장치로 전달합니다.
- **단축키와 로그인 실행** — 자주 쓰는 조절을 빠르게 실행합니다.
- **Bypass와 재연결** — 기본 오디오 경로로 돌아가거나 엔진을 다시 연결합니다.

## 처음 사용하기

1. 메뉴바의 MaxMix 아이콘을 클릭합니다.
2. 앱별 믹서를 쓰려면 **계속 · 오디오 접근 시작**을 누르고 macOS의 오디오 접근을 허용합니다.
3. 사용할 앱에서 소리를 재생한 뒤 목록의 볼륨과 음소거를 조절합니다.
4. 설정에서 마이크 EQ를 쓰려면 입력 마이크와 **EQ 출력**을 선택한 뒤 마이크 접근을 허용합니다.

마이크 EQ의 출력장치는 직접 선택해야 합니다. 시스템 기본 입출력은 바꾸지 않습니다.
통화·녹음 앱으로 전달하려면 입력 기능도 제공하는 출력장치를 선택하고, 사용할 앱에서도 해당 입력을 선택하세요.


## 지원 범위

장치 볼륨과 마이크 게인은 하드웨어가 해당 기능을 지원할 때 사용할 수 있습니다.
브라우저에서 같은 오디오 프로세스를 공유하는 탭은 브라우저 단위로 조절됩니다.
앱별 EQ와 전체 출력 EQ, 시스템 알림의 독립 볼륨 조절은 제공하지 않습니다.
마이크 EQ 입력과 출력은 서로 다른 장치여야 하며, 호환되는 Float32 PCM 형식과 샘플레이트가 필요합니다.

MaxMix는 오디오를 파일에 저장하거나 네트워크로 전송하지 않습니다.
외부 오디오 드라이버나 설치 프로그램을 포함하지 않습니다.
